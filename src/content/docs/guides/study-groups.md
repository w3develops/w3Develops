title: Study groups and book clubs
description: Learn a topic with others, with regular check-ins.
---
A study group is a small group learning the same thing, like JavaScript or system design. Book clubs work the same way around one book.

## Join or start one

- **Join:** open [Study Groups](https://w3develops.org/studygroups), pick one, and select **Join**.
- **Start:** select **Create**, give it a name, a topic and a short description, and set a meeting time if you have one.

## Inside a group

- **Check-ins:** post daily or weekly updates on what you did. Members of groups with a set time get a reminder before meetings.
- **Tasks:** a shared to-do list. Everyone in the group can add and tick off tasks; see all of yours on [My tasks](https://w3develops.org/account/my-tasks).
- **Leaving:** you can leave any time from the group page.
