## Web development basics (8 weeks)

Resources: [freeCodeCamp Responsive Web Design](https://www.freecodecamp.org/learn), [MDN Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development)

1. **Week 1:** how the web works; HTML structure and semantic tags.
2. **Week 2:** CSS basics: selectors, the box model, colors and fonts.
3. **Week 3:** layout with Flexbox; build a simple profile card.
4. **Week 4:** CSS Grid and responsive design; make the card work on a phone.
5. **Week 5:** forms and accessibility basics.
6. **Week 6:** Git and GitHub; put your work online with GitHub Pages.
7. **Week 7:** start a personal portfolio site.
8. **Week 8:** finish and show your portfolio.

## JavaScript (10 weeks)

Resources: [freeCodeCamp JavaScript](https://www.freecodecamp.org/learn), [javascript.info](https://javascript.info), [The Odin Project](https://www.theodinproject.com)

1. **Week 1:** values, variables, types and operators.
2. **Week 2:** conditionals and loops.
3. **Week 3:** functions and scope.
4. **Week 4:** arrays and array methods.
5. **Week 5:** objects; build a small to-do list in the console.
6. **Week 6:** the DOM and events; put the to-do list in a page.
7. **Week 7:** fetch and promises; call a public API.
8. **Week 8:** async/await and error handling.
9. **Week 9:** modules and a first look at a framework.
10. **Week 10:** a small project from [project ideas](https://w3develops.org/project-ideas).

## Python (8 weeks)

Resources: [Python's official tutorial](https://docs.python.org/3/tutorial/), [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/)

1. **Week 1:** setup, variables, input and output.
2. **Week 2:** conditionals and loops.
3. **Week 3:** functions.
4. **Week 4:** lists, dictionaries and sets.
5. **Week 5:** files and exceptions.
6. **Week 6:** modules, packages and virtual environments.
7. **Week 7:** a library of your choice (requests, pandas or Flask).
8. **Week 8:** a small command-line tool or script you'll actually use.

## Data structures and algorithms (8 weeks)

Resources: [Algorithms Daily](https://w3develops.org/algorithms-daily), [VisuAlgo](https://visualgo.net)

1. **Week 1:** Big-O and arrays.
2. **Week 2:** hash maps and sets.
3. **Week 3:** two pointers and sliding windows.
4. **Week 4:** stacks, queues and linked lists.
5. **Week 5:** recursion and binary search.
6. **Week 6:** trees and tree traversal.
7. **Week 7:** graphs: BFS and DFS.
8. **Week 8:** dynamic programming basics; mock interviews in pairs.

## Cloud and DevOps (6 weeks)

Resources: [roadmap.sh DevOps](https://roadmap.sh/devops), your cloud provider's free tier

1. **Week 1:** the command line and Linux basics.
2. **Week 2:** Git workflows and pull requests.
3. **Week 3:** containers with Docker.
4. **Week 4:** CI with GitHub Actions.
5. **Week 5:** deploying a small app to the cloud.
6. **Week 6:** monitoring, logs and infrastructure as code.
