w3develops.org is open source and built by volunteers. Code, writing, design and community help are all welcome.

- **[Set up locally](/docs/contributing/local-setup)**: Run the site on your computer.
- **[Git workflow](/docs/contributing/git-workflow)**: Branches, pull requests and reviews.
- **[Architecture](/docs/contributing/architecture)**: How the site is put together.
- **[Good first issues](https://github.com/w3develops/w3Develops/issues)**: Find something to work on.

Please read the [Code of Conduct](https://w3develops.org/code-of-conduct) and the [code style guide](https://github.com/w3develops/w3Develops/blob/main/docs/STYLE_GUIDE.md) before you start.
